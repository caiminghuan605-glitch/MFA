# 能源转型设备退役铜与次生铜核算（DMFA，设备量驱动版）

以 GCAM 32 区域为对象，两步完成：
1. **第一步**：以 `Output\保有量.xlsx` 为唯一设备路径（车辆=保有量 辆、发电=装机 MW），按批次寿命模型计算

2. **第二步**：在 **三个回收情景 × 两个废铜贸易情景** 下计算 **2021—2050 逐年次生铜产量**。

## 关键口径（摘要）

- **设备量驱动**：Q=保有量/装机；退役 R=ΣI·p(a)；新增 I=Q_t−Q_{t−1}+R_t；不再用铜存量面板反推退役。
- **初始化**：每个序列首个正值节点 t0 为初始批次（年龄0、当年不退役）；t<t0 无投入无退役；空白不填0；全零序列保持0。
- **提前退役**：I<0 时缺口全部记为“经济性提前退役”（最老批次优先），单列于提前退役面板；只由设备量下降触发，与自然退役分列。
- **铜强度**：每批次按投入年强度固定（A 方案）；车辆用 Automotive（kg/vehicle），发电用 CIPG（≤2021用2021值，节点间线性插值，禁止2025→2030跳配）。
- **水电**：CON 规模份额直接拆装机；规模寿命 50/70/80 年；规模强度取补充表5（大型49:15加权）并按项目 CIPG 路径归一；正式结果汇总为一条 hydro。
- **年份模板**：替换前读取旧成果的年份列（车辆 2010—2050、绿电 1990—2050、第二步 2021—2050），新面板严格沿用。
- 15 个有处理能力的区域与 17 个全出口区域由贸易矩阵对角线确定；“17 区无本地处理能力”是研究设定。
- 全球开放：收集率取废铜产生地、综合处理率取实际处理地；七类设备统一沿用同一贸易矩阵（本研究外推）。
