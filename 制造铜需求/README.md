# 制造铜需求项目说明

## 1. 项目目的

把 GCAM 情景下各地区的**新能源汽车保有量**和**绿电设备装机容量**，按对应的**制造需铜系数**换算为**现有设备所含的制造用铜量**，输出车辆与绿电两张宽面板。

- 结果是**存量设备对应铜量**，不是年度新增铜需求。
- 未做年度差分、寿命报废、更新替换、回收抵扣、二次加工或价格/贸易修正。
- 本次只调整输出结构，铜量计算方法与系数不变。

## 3. 计算口径

```
车辆铜量(t) = 保有量(辆) × 需铜系数(kg/vehicle) ÷ 1000
绿电铜量(t) = 装机容量(MW) ÷ 1000 × 需铜系数(t/GW)
```

年份系数映射：

| 数据年份 | 使用的 CIPG 年份 |
|---|---|
| 2010 | 2021 |
| 2015 | 2021 |
| 2021 | 2021 |
| 2025 | 2030 |
| 2030–2050 | 当年 |

- 中间值全精度；最终 `铜量(t)` 按既有方法 `floor(x+0.5)` 取整。
- 面板转换阶段不再二次取整。

## 5. 程序结构

`copper_demand.py` 是唯一主程序：

1. 只读读取两个工作簿；
2. 结构勘察与映射覆盖校验；
3. 车辆/绿电铜量长表计算；
4. 转换前检查“标识字段+年份”重复；
5. 长表→两张面板；
6. 写临时 xlsx，重新打开逐键逐年核验；
7. 核验通过后替换正式 Excel。

程序不依赖被覆盖前的旧长表文件，直接从上游数据计算。

## 8. 文献与待核实

方法文档按 [1]–[4] 说明系数来源，并区分文献原值、单位换算、代理取值与项目假设。关键待核实：

- `refined liquids_CC_CCS` 的 1100 t/GW：项目口径说明标注 Tokimatsu et al. (2018) Table 3，但不在 [1]–[4] 中；提供的 `liquids_CCS参考文献.pdf` 是 [2]，正文明确排除 oil-fired generation，**来源待核实**。
- [4] 表 4 核对：`Car` 的 BEV 项目值 26.4 与表 4 BEV 121.3 不一致（等于 ICE 26.4），**待核实**；PHEV 除 Medium 外等于表 4 `(HEV+PHEV)/2`，属代理取值；Medium 的 154.25 与均值 154.70 差 0.45。
- [3] 仅支撑 CSP；本次 8 类中没有 CSP，不能把 [3] 当作 PV 或 refined liquids CCS 的依据。
